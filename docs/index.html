Getting Started

몇 분 안에 KiwoomRestApi.Net을 시작할 수 있습니다.

1. Installation

dotnet add package KiwoomRestApi.Net

2. Basic Usage

using KiwoomRestApi.Net.Clients; using KiwoomRestApi.Net.Enums.StockInfo; // 클라이언트 생성 var client = KiwoomRestApiClient.Create("YOUR_APP_KEY", "YOUR_SECRET_KEY", isMock: true); // 삼성전자 주식 정보 가져오기 var stockInfo = await client.StockInfo.GetStockInfoAsync( stockCode: "005930", date: DateTime.Today, marginLoanType: KiwoomStockInfoMarginLoanType.Loan ); if (stockInfo.IsSuccess) { Console.WriteLine($"Stock: {stockInfo.Data?.StockName}"); Console.WriteLine($"Price: {stockInfo.Data?.CurrentPrice:N0} KRW"); } else { Console.WriteLine($"Error: {stockInfo.ReturnMessage}"); }
Note: 개발 및 테스트 시에는 isMock: true로 설정하여 모의투자 모드를 사용하세요. 프로덕션 준비가 되면 false로 변경하세요.
