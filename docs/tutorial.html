Getting Started

Setup

Prerequisites

  • .NET 6.0 이상
  • Visual Studio 2022 또는 VS Code
  • 키움증권 계정 및 API 접근 권한
  • 키움 OpenAPI에서 발급받은 앱 키와 시크릿 키

Installation

NuGet 패키지를 설치하세요:

dotnet add package KiwoomRestApi.Net
Tip: NuGet 패키지 관리자 콘솔에서도 설치할 수 있습니다: Install-Package KiwoomRestApi.Net

Basic Project Setup

using KiwoomRestApi.Net.Clients; var appKey = "YOUR_APP_KEY"; var secretKey = "YOUR_SECRET_KEY"; var isMock = true; // 실거래의 경우 false로 설정 // 클라이언트 생성 var client = KiwoomRestApiClient.Create(appKey, secretKey, isMock);

Basic Usage

Data

Getting Stock Information

삼성전자(005930)의 기본 주식 정보를 가져와 보겠습니다:

using KiwoomRestApi.Net.Enums.StockInfo; // 삼성전자(005930) 주식 정보 가져오기 var stockInfo = await client.StockInfo.GetStockInfoAsync( stockCode: "005930", date: DateTime.Today, marginLoanType: KiwoomStockInfoMarginLoanType.Loan ); if (stockInfo.IsSuccess) { Console.WriteLine($"주식명: {stockInfo.Data?.StockName}"); Console.WriteLine($"현재가: {stockInfo.Data?.CurrentPrice:N0} KRW"); Console.WriteLine($"변동률: {stockInfo.Data?.ChangeRate:F2}%"); Console.WriteLine($"거래량: {stockInfo.Data?.Volume:N0}"); } else { Console.WriteLine($"오류: {stockInfo.ReturnMessage}"); }

Handling Real-time Events

// 주식 체결 이벤트 socketClient.OnRealtimeStockTradeReceived += (realtimeData) => { foreach (var data in realtimeData) { Console.WriteLine($"[{data.Item}] {data.Values.CurrentPrice} " + $"({data.Values.ChangeRate:F2}%) " + $"거래량: {data.Values.AccumulatedVolume:N0}"); } }; // 주문 체결 이벤트 socketClient.OnRealtimeOrderTradeReceived += (orderData) => { foreach (var order in orderData) { Console.WriteLine($"주문 업데이트: {order.Values.OrderId} - {order.Values.OrderStatus}"); } }; // 잔고 이벤트 socketClient.OnRealtimeBalanceReceived += (balanceData) => { foreach (var balance in balanceData) { Console.WriteLine($"잔고 업데이트: {balance.Values.StockName}"); Console.WriteLine($"보유 수량: {balance.Values.HoldingQuantity}"); } };

Advanced Features

Advanced

Pagination

대량의 데이터를 조회할 때 페이지네이션을 사용할 수 있습니다:

// 첫 페이지 조회 var firstPage = await client.Chart.GetTickChartsAsync("005930", 1, false); // 다음 페이지가 있으면 if (firstPage.ContYn) { client.ContYn = true; client.NextKey = firstPage.NextKey; var secondPage = await client.Chart.GetTickChartsAsync("", 1, false); // 초기화 client.ContYn = false; client.NextKey = ""; }

Pagination Loop

모든 페이지를 순회하는 방법입니다:

// 모든 페이지를 순회하는 루프 var response = await client.Chart.GetTickChartsAsync("005930", 1, false); while (response.IsSuccess) { foreach (var item in response.Data?.Items ?? Enumerable.Empty<KiwoomChartGetTickChartItem>()) { Console.WriteLine($"{item.CurrentPrice}"); } if (!response.ContYn) break; client.ContYn = true; client.NextKey = response.NextKey; response = await client.Chart.GetTickChartsAsync("", 1, false); } client.ContYn = false; client.NextKey = "";

Error Handling

Advanced

Handling API Errors

try { var result = await client.StockInfo.GetStockInfoAsync( stockCode: "005930", date: DateTime.Today, marginLoanType: KiwoomStockInfoMarginLoanType.Loan ); if (!result.IsSuccess) { Console.WriteLine($"API Error [{result.ApiId}]: {result.ReturnMessage}"); return; } // 성공 처리 Console.WriteLine($"Stock: {result.Data?.StockName}"); } catch (HttpRequestException ex) { Console.WriteLine($"HTTP Error: {ex.Message}"); } catch (TaskCanceledException) { Console.WriteLine("Request timed out."); } catch (Exception ex) { Console.WriteLine($"Unexpected error: {ex.Message}"); }
Note: API 오류는 IsSuccess == false로 반환됩니다. 네트워크 오류 등은 예외로 발생합니다.

Best Practices

Setup

Connection Management

// IDisposable을 활용한 적절한 해제 using var client = KiwoomRestApiClient.Create(appKey, secretKey, isMock); using var socketClient = KiwoomSocketClient.Create(client.Token, isMock); // API 호출...

Rate Limiting

API 호출 시 속도 제한을 구현하는 것이 좋습니다:

// PagingDelay 속성을 활용한 페이지네이션 지연 client.PagingDelay = 1000; // 페이지 간 1초 지연 (ms) // 또는 SemaphoreSlim을 사용한 수동 제한 private readonly SemaphoreSlim _semaphore = new(1, 1); public async Task<T> ExecuteWithLimitAsync<T>(Func<Task<T>> apiCall) { await _semaphore.WaitAsync(); try { var result = await apiCall(); await Task.Delay(TimeSpan.FromMilliseconds(100)); return result; } finally { _semaphore.Release(); } }
Pro Tip: 개발 및 테스트 시에는 항상 모의투자 모드로 시작하세요. 프로덕션 준비가 되었을 때만 실제 API 키로 전환하세요.
